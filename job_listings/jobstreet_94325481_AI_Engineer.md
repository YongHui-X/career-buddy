## Job Description

### About the role

This role involves developing core AI Agent capabilities and designing agentic workflows to support advanced AI systems.

### Key responsibilities

- Develop core AI Agent capabilities, including task planning, task decomposition, tool invocation, memory system, state management, and result verification
- Design and implement Agentic Workflows, such as scheduled tasks, automated task execution, periodic report generation, automated information retrieval, and automated summarization
- Participate in the construction of multi-Agent systems, including the collaboration of roles such as Planner Agent, Executor Agent, Reviewer Agent, and Memory Agent
- Support the development of multiple clone applications, such as multiple digital clones running in parallel, maintaining different contexts, and executing different tasks
- Integrate with large model APIs, local models, RAG knowledge bases, and business systems to improve Agent task completion rate and stability
- Design Agent operation logs, task tracking, failure retry, manual review, and security control mechanisms
- Participate in Agent performance evaluation, including task success rate, illusion rate, response latency, cost, and user satisfaction
- Continuously follow up on Agent frameworks such as LangChain, LangGraph, LlamaIndex, AutoGen, and CrewAI, and make technology selections based on business scenarios

### About you (requirements)

- 1-3 years of experience in AI engineering, backend development, NLP, machine learning, or LLM application development
- Proficient in Python with strong backend engineering skills
- Familiar with at least one Agent or LLM application framework, such as LangChain, LangGraph, LlamaIndex, AutoGen, or CrewAI
- Familiar with Prompt Engineering, Function Calling, Tool Calling, RAG, Embedding, and vector databases
- Experience with scheduled tasks, asynchronous task queues, automated workflows, and SaaS systems is **preferred**
- Experience with Chinese corpora, Chinese agents, or Chinese business scenarios is **preferred**
